# Changelog

All notable changes to this project will be documented on this page.

<Changelog>
  <ChangelogEntry version="1.3.1" date="2026-02-19" type="minor">
    <ChangelogItem type="added">
      Custom font support — configure heading, body, and code fonts via `branding.fonts` in `docs-config.json`
    </ChangelogItem>
    <ChangelogItem type="added">
      Dynamic Google Fonts loading — fonts are fetched based on your config, no template changes needed
    </ChangelogItem>
    <ChangelogItem type="changed">
      Landing page templates now use dynamic font loading instead of hardcoded font links
    </ChangelogItem>
  </ChangelogEntry>

  <ChangelogEntry version="1.0.0" date="2026-02-10" type="major" badge="Stable">
    <ChangelogItem type="added">
      Dual publishing to npm and GitHub Packages
    </ChangelogItem>
    <ChangelogItem type="changed">
      Decluttered navbar — version/language switchers moved to sidebar, social links reorganized
    </ChangelogItem>
    <ChangelogItem type="changed">
      CLI version now reads dynamically from `package.json` — no more version drift
    </ChangelogItem>
    <ChangelogItem type="changed">
      Version and language switchers support multiple instances (sidebar + mobile nav)
    </ChangelogItem>
    <ChangelogItem type="fixed">
      npm package reduced from 31 MB to 39 KB with proper `files` field
    </ChangelogItem>
    <ChangelogItem type="fixed">
      CLI version mismatch — update checker was stuck at v0.5.2
    </ChangelogItem>
  </ChangelogEntry>
  <ChangelogEntry version="0.7.0" date="2026-01-28" type="major">
    <ChangelogItem type="added">

    </ChangelogItem>
    <ChangelogItem type="added">
      Custom landing pages with full HTML/CSS/JS control or section-based layouts
    </ChangelogItem>
    <ChangelogItem type="added">

    </ChangelogItem>
    <ChangelogItem type="added">
      Template registry with shorthand names (astro, react, next, vue, nuxt)
    </ChangelogItem>
    <ChangelogItem type="added">
      Configuration validation system with portable config support
    </ChangelogItem>
    <ChangelogItem type="changed">
      Framework-aware build pipeline with HMR support for Vite-based frameworks
    </ChangelogItem>
    <ChangelogItem type="changed">
      Enhanced CLI UX with interactive prompts, spinners, and color-coded output
    </ChangelogItem>
  </ChangelogEntry>
