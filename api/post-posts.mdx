## Overview

Creates a new blog post. Requires authentication.

## Authorization

<Alert type="info">
  This endpoint requires a Bearer token for authentication.
</Alert>

## Request Body

<ParamTable type="body">
  <Param name="title" type="string" required>
    Title of the post
  </Param>
  <Param name="body" type="string" required>
    Content of the post. Supports plain text or markdown.
  </Param>
  <Param name="userId" type="integer" required>
    ID of the user creating the post
  </Param>
</ParamTable>

## Response

Returns the created post object with the assigned ID.

<ResponseField name="id" type="integer">
  The auto-generated unique identifier for the new post
</ResponseField>

<ResponseField name="title" type="string">
  The title provided in the request
</ResponseField>

<ResponseField name="body" type="string">
  The content provided in the request
</ResponseField>

<ResponseField name="userId" type="integer">
  The user ID provided in the request
</ResponseField>

## Error Responses

| Status | Description |
|--------|-------------|
| `400` | Invalid request body - missing required fields |
| `401` | Unauthorized - missing or invalid Bearer token |

<Tabs items={["cURL", "JavaScript", "Python"]}>
  <Tab title="cURL">
    ```bash
    curl -X POST "https://jsonplaceholder.typicode.com/posts" \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer <token>" \
      -d '{
        "title": "My First Blog Post",
        "body": "This is the content of my first blog post.",
        "userId": 1
      }'
    ```
  </Tab>
  <Tab title="JavaScript">
    ```javascript
    const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer <token>"
      },
      body: JSON.stringify({
        title: "My First Blog Post",
        body: "This is the content of my first blog post.",
        userId: 1
      })
    });

    const data = await response.json();
    console.log(data);
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    response = requests.post(
        "https://jsonplaceholder.typicode.com/posts",
        headers={"Authorization": "Bearer <token>"},
        json={
            "title": "My First Blog Post",
            "body": "This is the content of my first blog post.",
            "userId": 1
        }
    )
    print(response.json())
    ```
  </Tab>
</Tabs>
