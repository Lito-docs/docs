# Welcome to Lito v1

Lito v1 is the original release of the documentation generator. This version supports basic Markdown rendering with Astro.

## Features in v1

- **Markdown Support** — Write your docs in `.md` files
- **Sidebar Navigation** — Auto-generated from file structure
- **Basic Theming** — Simple color customization via config
- **Static Site Output** — Fast, deployable HTML

## Limitations

<Alert type="warning">
  Lito v1 does not support MDX components, i18n, or custom landing pages. Consider upgrading to the latest version for these features.
</Alert>
