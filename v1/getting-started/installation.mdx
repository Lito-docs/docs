# Installation (v1)

## Prerequisites

- **Node.js**: Version 16.0.0 or higher
- **npm** package manager

## Install

```bash
npm install -g @litodocs/cli@1
```

## Usage

```bash
lito dev -i ./my-docs
```

<Alert type="note">
  Lito v1 only supports the Astro template. For React, Next.js, Vue, and Nuxt support, upgrade to the latest version.
</Alert>
