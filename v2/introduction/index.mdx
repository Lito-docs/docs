# Welcome to Lito v2

Lito v2 introduced MDX support, a redesigned theme system, and the component library that makes Lito a true Mintlify alternative.

## What's New in v2

<Steps>
  <Step title="MDX Components">
    20+ built-in components — Cards, Tabs, Steps, Alerts, Code Groups, and more.
  </Step>
  <Step title="Custom Theming">
    Full OKLCH color system with primary, gray, and semantic color palettes.
  </Step>
  <Step title="Multi-Framework Templates">
    Choose between Astro, React, Next.js, Vue, or Nuxt templates.
  </Step>
  <Step title="API Documentation">
    Auto-generated API reference pages from OpenAPI specs.
  </Step>
</Steps>

## v2 vs Latest

<Alert type="info">
  Lito v2 does not include i18n support, custom landing pages, or the version switcher. These were added in v3 (latest).
</Alert>
